🟡 PacMan GPS

Juego Clásico de Pac-Man en Java

✅ Java 17 🧪 100% Coverage 🚀 CI/CD Ready 🎮 Open Source

✨ Características Principales

🎮

Jugabilidad Clásica

Experiencia fiel al juego original con controles intuitivos y mecánicas clásicas de Pac-Man.

⚡

Habilidades Especiales

Tres vidas, impulso de velocidad y power-ups adicionales para una experiencia mejorada.

🎯

Niveles de Dificultad

Tres niveles de dificultad (Fácil, Normal, Difícil) que afectan el comportamiento de los fantasmas.

👾

IA Inteligente

Fantasmas con movimiento automático y comportamiento adaptativo para un desafío real.

🕹️ Controles del Juego

⬆️

Flecha Arriba

Mover hacia arriba

⬇️

Flecha Abajo

Mover hacia abajo

⬅️

Flecha Izquierda

Mover a la izquierda

➡️

Flecha Derecha

Mover a la derecha

💻 Tecnologías Utilizadas

Java 17 Swing GUI Maven JUnit 5 Mockito JaCoCo GitHub Actions

📋 Requisitos del Sistema

  • Java Runtime Environment (JRE) 17 o superior
  • Sistema Operativo: Windows, macOS, Linux
  • Memoria RAM: Mínimo 512 MB disponible
  • Espacio en Disco: 50 MB libres

🚀 Cómo Ejecutar

1. Descargar el archivo JAR

2. Abrir terminal/consola en la carpeta de descarga

3. Ejecutar el comando:

java -jar pacman-game-1.0.0.jar

4. ¡Disfruta del juego! 🎮

🎯 Objetivo del Juego

🟡 Recoge todos los puntos del laberinto mientras evitas a los fantasmas 👻
💊 Usa los power-ups para volverte invencible temporalmente
⚡ Aprovecha las habilidades especiales para superar desafíos
🏆 ¡Completa todos los niveles y alcanza la puntuación más alta!
